# Projeto Avaliativo 3: Módulo de Contatos B2B (C++)

Este projeto é um módulo de Gestão de Contatos de Clientes (CRM) focado em alta performance, desenvolvido em C++. Ele implementa conceitos de Orientação a Objetos e gerenciamento dinâmico de memória utilizando a Standard Template Library (STL).

## Estrutura do Projeto
- `docs/`: Contém o diagrama de classes UML.
- `src/`: Contém os códigos-fonte (`Contato.h`, `Contato.cpp`, `main.cpp`).

## Como compilar

Para compilar o código usando o compilador GCC, abra o terminal na raiz do projeto e execute o seguinte comando:

```bash
g++ src/main.cpp src/Contato.cpp -o crm_app
