
# Projeto Avaliativo 3 — Introdução a C++

Projeto desenvolvido em C++ para gerenciamento de contatos corporativos, utilizando conceitos fundamentais da linguagem como:

- Classes
- Construtor e destrutor
- Encapsulamento
- `std::vector`
- Separação `.h` e `.cpp`

---

# Funcionalidades

- Cadastro de contatos
- Impressão de nome e telefone
- Uso de `std::vector`
- Log de desalocação de memória no destrutor

---

# Compilação

```bash
g++ src/main.cpp src/Contato.cpp -o crm_app
````

---

# Execução

Linux/MacOS:

```bash
./crm_app
```

Windows:

```bash
crm_app.exe
```
