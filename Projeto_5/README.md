# Sistema Acadêmico Ampliado em C++

## Descrição do Projeto

Este projeto foi desenvolvido em C++ com o objetivo de aplicar os principais conceitos de Programação Orientada a Objetos (POO), incluindo:

- Herança
- Herança Múltipla
- Polimorfismo
- Sobrescrita (Override)
- Sobrecarga (Overload)
- Classes Abstratas
- Modularização com arquivos `.h` e `.cpp`

O sistema representa um ambiente acadêmico capaz de gerenciar:

- Alunos
- Professores
- Funcionários Administrativos
- Monitores

Cada tipo de usuário possui características específicas e relatórios personalizados.

---

# Objetivos do Projeto

O projeto tem como finalidade reforçar conceitos avançados de POO utilizando uma aplicação prática e organizada.

Também busca demonstrar:

- Reutilização de código através de herança
- Flexibilidade com polimorfismo
- Organização modular
- Escalabilidade do sistema
